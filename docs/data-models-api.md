Cohort price/m² percentiles (v0.14-s1.6, written only by `adapters/metrics/scoring.py` from `core/cohort_percentile.py`): `price_per_m2_percentile_rent` / `_sale` (share of the city × neighbourhood × listing-type cohort priced at or below the Property, in (0, 1], lower is cheaper; NULL below `scoring.percentile_min_cohort_size` or when the Property is not a cohort member), `percentile_cohort_size_rent` / `_sale`, `percentile_evaluated_at` (NULL until the stage evaluates the row); range CHECKs. Price-drop alerts (v0.14-s1.10): `price_drop_enabled_at` (naive UTC, the moment alerts were on with a threshold stored: the floor a drop is measured from), `price_drop_last_window_on` (local date of the last drop email) |

## Key relationships

- `properties 1—N property_listings` (cross-platform dedupe collapses listings onto one property).
- `properties 1—N price_history`; history is per listing-type/platform cohort.
- `properties 1—1 metrics_scoring` (with per-listing-type score columns).
- Personalization tables (`watchlist`, `saved_searches`, `favourites`) are owner-scoped (nullable owner — single-user for now).
